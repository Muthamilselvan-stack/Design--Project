# IRCTC App Redesign – UX/UI Case Study

This repository contains a UX/UI redesign case study of the IRCTC mobile application.  
The goal of this project was to improve usability, navigation clarity, and the overall ticket booking experience.

## Project Overview
- Conducted a usability audit on the existing IRCTC app
- Identified key user pain points in navigation and booking flow
- Redesigned core screens with a cleaner UI and better user experience
- Focused on simplicity, accessibility, and task efficiency

## Tools Used
- Figma
- UX Research
- Usability Audit
- Information Architecture

## Design Screens
All redesigned screens are uploaded as PNG files in the **screens** folder.

Screens include:
- Login Screen
- Home Screen
- Search & Booking Flow
- Passenger Details
- Payment Screen

## Outcome
The redesign improves task flow, reduces visual clutter, and provides a smoother booking experience compared to the original app.
